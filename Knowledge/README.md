# Knowledge — `KNOW`

Reference material: domain knowledge, technical facts, general topics, standards. Things that are true or explain something, not things being done.

Filenames: `KNOW-<NNNN>-<slug>.md`

Create from `_TEMPLATE.md` using `_HOW-TO-CREATE.md`.

## Before changing this folder

- File only durable, reusable learning; task-local observations belong in their Project, Ticket, or Chat.
- For a new record, reserve the `KNOW` ID, satisfy base frontmatter, use `current` or `superseded` status, and add evidence-backed reciprocal links.
