# Planning — optional execution detail

Small work uses an inline Work plan checklist in its authoritative Ticket/Project. Substantial work may use exactly one `Planning/<PARENT-ID>.md`. Keep existing plans as history.

Create a companion from `_TEMPLATE.md` using `_HOW-TO-CREATE.md`.

A companion contains `Parent: [[PARENT-ID]]`; the parent contains `Live plan: Planning/<PARENT-ID>.md`. The parent owns status, evidence and next action. Validate both pointers and preserve dependencies/decisions already recorded.

Required sections when a companion is used: Objective, Work plan, Next executable steps. Add other sections only when useful. Done work cannot retain executable unchecked requirements, whether inline or in a companion.

Update at meaningful state/evidence changes. Repair only contradictions that block resumption; no compulsory portfolio or forecasting cycle.
