# Testing & Validation — Generic Definition of Done

## Trigger

A requested result needs verification.

## Method

Name the acceptance claim. Inspect actual objects and run applicable tests/readback. Reuse unchanged evidence; obtain independent authored-code review and any actual specialist/customer acceptance. Correct only relevant failures and recheck affected requirements. Record one truthful result.

## Stop

Acceptance proven or precise blocker. Simulation is not production execution; no nine-stage role chain, full-roster closure or automatic production promotion.

AGENTS.md owns shared authority, evidence reuse and task boundaries.
