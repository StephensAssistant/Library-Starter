# Decision & Prioritisation — Triaging Competing Demands

## Trigger

Two or more actual demands compete, or the Library owner asks what next.

## Method

Read the competing records and their decision-relevant dependencies. Reuse the Library owner's current recorded priority. Ask when it is missing, conflicting or material new evidence makes it uncertain. Never infer priority from age, status, working hours or prior ordering. Retain explicit commitments. When the Library owner has not supplied a complete ordering, use the relevant canonical work record §7 for executable Tickets, including its prerequisite exception. For other demands, protect confirmed commitments first, then weigh customer/business impact, deadlines, dependencies, delivery risk and effort. In a mixed queue, explain any trade-off against a protected commitment and leave the decision with the Library owner. Evidence outranks labels; state material gaps. Return the three highest-ranked demands—or fewer when fewer genuinely compete—with an evidence-based confidence percentage, supporting evidence, and the trade-off or consequence of selecting each. Confidence expresses decision confidence, not statistical probability, and scores need not total 100%. Report confidence alongside the priority order, even when no option reaches 95%. Confidence describes the evidence for the recommendation and does not reorder commitments or replace AGENTS.md's operational-quality release score. Clearly identify the highest-supported option as the recommended next item and state its uncertainty. Use SKILL-0318's independent question rounds only when missing information could materially change the ordering. Use the Board for discovery and verify the owning records. Apply the relevant canonical work record's capacity rules to the time the Library owner has actually supplied. If capacity is unknown, give a ranked queue. If a new demand competes with an active commitment, name what would move, the consequence of deferring it, and the smallest useful next action that fits the known window. Return the trade-off to the Library owner before changing priority or commitments.

## Stop

One clearly recommended next action within a ranked top three, each with confidence, evidence and trade-off; or the precise decision-changing unknowns. the Library owner's stated current priority overrides the default hierarchy. No fabricated scoring, universal WIP ceilings or reprioritisation of unrelated work.

AGENTS.md owns shared authority, evidence reuse and task boundaries.

## Decision-first routing — 10 October 2026

SKILL-0318 is the first decision workflow whenever a consequential unresolved choice affects the next action, throughout the work. Perform the required evidence/intake checks first, then ask the current round of independent material decision questions under SKILL-0318, use the answers to define the correct steps, and reassess the complete applicable Hats, Skills, Playbooks and confirmed associations under SKILL-0113 before dependent execution. Reuse settled answers; return only to affected decisions when evidence or requirements changes. Clear agreed work proceeds directly. the Library owner's standing instruction replaces the former explicit-invocation-only restriction; it grants no extra external-action authority.
