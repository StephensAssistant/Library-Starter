# Estate Hygiene & Orphan Sweep

## Trigger

the Library owner explicitly requests maintenance, or closure needs task-owned residue checked.

## Method

Inspect only the named scope and actual affected links. Preserve canonical records/evidence. Clean task-owned temporary files only when authorized and their needed content is preserved; report an unresolved disposition rather than deleting unrelated material.

## Stop

Named scope complete. No idle-capacity or whole-estate sweep, mandatory empty sweep receipt or automatic follow-on work.

AGENTS.md owns shared authority, evidence reuse and task boundaries.
