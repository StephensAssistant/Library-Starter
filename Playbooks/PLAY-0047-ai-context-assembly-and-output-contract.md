# AI Context Assembly and Output Contract

## Trigger

Context or durable state is needed for a task.

## Method

Use [[PLAY-0006]] entry and [[PLAY-0033]] checkpoint. Read the named current record and assemble the complete required Playbook/Skill association closure under AGENTS.md, including confirmed links, declared dependencies, explicit references and registered intent routing. Apply the loaded instructions at their actual responsibility boundaries; association loading does not expand action scope. When subject/dependencies change or facts are missing, search for supporting and conflicting evidence and inspect the sources. Discovery matches remain unconfirmed; add relationships only with confirmed evidence and governed reciprocal updates. Save meaningful state once within authority.

## Recall before deciding

Resolve the subject from the Library owner's current wording and the canonical record; an application sharing a name with the Library is not interchangeable with the Library itself. Before recommending, retrieve relevant previous attempts, decisions, reusable capabilities and counter-evidence. Read the matching source section, not just its title or search excerpt. Record the source revision and its effect on the recommendation in the existing work owner; reuse that assessment until evidence changes.

When the Library owner's way of working affects the response, consult the applicable preferences in the owner’s configured preferences. Use them across assistants and Hats, giving their current instruction precedence. Reuse preferences already established so he does not have to repeat them.

A failed tool read is an access gap; a stale derived index is a freshness gap; an omitted or poorly ranked existing source is a retrieval gap. None proves knowledge is absent. Check the explicit branch and canonical source before recording a bounded negative search. Repository retrieval currently indexes ID-bearing records; read linked plans and daily chat provenance directly when needed. Research unresolved facts, then apply AGENTS.md's alignment boundary before implementation.

## Stop

Enough current context for the next step and a resumable checkpoint. No second framing pass, compulsory capsule or unrelated broad search. Verified reusable Skill gaps must be captured automatically under AGENTS and the Library owner's standing authority; that bounded capture is not a compulsory new record for routine task-local observations.

AGENTS.md owns shared authority, evidence reuse and task boundaries.
