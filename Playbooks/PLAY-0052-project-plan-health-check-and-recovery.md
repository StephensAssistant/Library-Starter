# Project Plan Health Check and Recovery

## Trigger

A contradiction or missing next action prevents resumption.

## Method

Compare parent, used plan and direct evidence. Repair only the blocking discrepancy within scope, keeping the parent authoritative. Preserve obsolete/deferred history and set the evidenced next action.

## Stop

Work can resume under [[PLAY-0050]], or exact unresolved truth is reported. No whole-portfolio plan audit.

AGENTS.md owns shared authority, evidence reuse and task boundaries.
