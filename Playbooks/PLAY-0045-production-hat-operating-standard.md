# Production Hat Operating Standard

## Trigger

Authoring guidance for specialist expertise is needed.

## Method

Define the actual domain responsibility and necessary evidence. Use expertise only when triggered by the task; independent authored-code review remains required. Follow AGENTS for authority, scope and stopping.

## Stop

Sufficient expertise applied. No runtime Hat activation record, 12-element score, all-seat enumeration or mandatory review date.

AGENTS.md owns shared authority, evidence reuse and task boundaries.
