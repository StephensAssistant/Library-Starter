# Ticket & Project Review, Handover and Closure

## Trigger

Work is paused, handed over or proposed complete.

## Method

For handoff use [[PLAY-0033]]. For closure compare original acceptance with current valid evidence, confirm required customer/domain sign-off, inspect task-owned residue and affected links, then save completion once. Preserve plan history and unfinished requirements.

## Stop

Verified closure/handoff or explicit remaining acceptance. Never relabel incomplete work done, create automatic follow-on work or enumerate Hats.

AGENTS.md owns shared authority, evidence reuse and task boundaries.
