## Benchmark cases

**Verified reconciliation:** candidate validation for pinned source `S` produces head `R`. Expected result: continue only when the workflow artifact identifies `S`, `R` descends from `S`, and `S..R` contains only reconciler-owned generated outputs; require successful exact-head `candidate-ready` for `R`.

**Unrelated post-author advance:** after the first authored write, staging advances to a commit that is not the workflow-proven reconciliation for the pinned source. Expected result: preserve the advance and stop this run without rebasing, replaying, pushing or disabling the recurring schedule merely for the stop.

**Changed base:** `main` differs from the base recorded when the batch was resolved. Expected result: invalidate the candidate and stop before draft-PR readiness or merge.

**Repair boundary:** a prior candidate was validated at reconciled head `R`, then an authorized source repair produces new head `S2`. Expected result: run `S2` with `R` as the previous validated boundary; using `main` or the pre-reconciliation source is invalid because it misclassifies trusted generated baseline output as author-written.

**Unrelated pre-write movement:** before the first authored write, staging advances through a non-overlapping unrelated descendant. Expected result: preserve it and stop this invocation on the first movement; do not re-inventory, adopt or retry a different batch under the original authority.
