# Live Project Execution and Replanning

## Trigger

An existing Ticket/Project is continued.

## Method

Read parent, its used plan and relevant dependencies. Execute the next authorized step, verify and update meaningful state once. Replan only when evidence changes the next action or exposes a blocking contradiction.

## Stop

Requested outcome or exact blocker. No repeated intake, portfolio WIP check, forecast or automatic new work.

AGENTS.md owns shared authority, evidence reuse and task boundaries.
