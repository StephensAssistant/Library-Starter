# Guided Learning and Mastery

## Trigger

the Library owner explicitly asks to learn.

## Method

Explain at requested depth using current source-backed facts. Check understanding when requested or useful to the agreed objective; reteach demonstrated gaps. If assessing mastery, use taught prerequisites and actual demonstrated application.

## Stop

Agreed learning outcome or concise explanation delivered. No automatic three layers, exam, Learning Ticket, knowledge capture or review schedule. Schedule only when asked.

AGENTS.md owns shared authority, evidence reuse and task boundaries.

## Matt Pocock method extension — 2026-10-10

Start with the learner's current knowledge and one scoped capability or practical win. Connect the mission to concrete work, explain through a small example, ask the learner to retrieve or apply it, and use their observed result to choose the next step. Record learning evidence in the existing learning owner when authorised; glossary/resources/mission notes support it without becoming parallel state stores. Offer later practice only when useful and schedule it only on request. Do not impose a full course, examination or repeated mastery records for a single explanation.
