# Customer Communication — Closure

## Trigger

Delivered work needs customer acceptance.

## Method

Compare delivery with actual acceptance criteria. Draft the send-ready confirmation under [[PLAY-0034]] for the Library owner to review and send. Record real customer acceptance or the Library owner's explicit alternate disposition; changes return to the affected work.

## Stop

Verified acceptance supports closure, or the work remains awaiting acceptance. Silence is not confirmation.
