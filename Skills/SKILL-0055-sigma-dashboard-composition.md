# Sigma Dashboard Composition

Compose premium Sigma dashboards with measurable hierarchy, spacing, grouping and readable component sizing.

## When to use

Use when arranging workbook elements into a polished dashboard or reusable visual component.

## Method

1. Use the 24-column canvas and Small workbook spacing as the Library owner's current default; the verified tenant options are Small, Medium and Large.
2. For containers, default to High density, Small spacing, Padding Off and Element Gap Off unless testing disproves it.
3. Apply perceptual grouping: proximity, similarity, continuation, common fate, closure, symmetry and figure-ground.
4. Use tenant-tested KPI baselines: trend container 4×8 with KPI 15×4, icon 8×4 and area chart 24×4; compact container 4×4.
5. Validate five-second comprehension, scan order, readability, comparison speed, interaction area and responsive integrity.

## Benchmark case

A six-card landing row uses verified component sizes and produces one clear hierarchy without truncation or misleading grouping.

Boundary design case: the tenant-tested KPI dimensions truncate a longer label at the intended viewport. Preserve the metric meaning and test a readable composition; report the actual viewport result rather than treating the baseline dimensions or an attractive screenshot as acceptance.

## Anti-patterns

- Inventing Sigma capabilities, identifiers, schemas or successful evidence.
- Duplicating governed logic without a measured reason.
- Treating a syntactically accepted change as verified behaviour.

## Stop

Stop after the named outcome is read back and verified, or the precise capability, access, source or evidence gap.
