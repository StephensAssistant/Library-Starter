# Evidence-Guided Learning Proposal

Designs the smallest evidence-backed improvement to ineffective guidance.

## When to use

Use after a classified missed, failed or cross-context learning event warrants a proposal.

## Method

1. State occurrence evidence and diagnosed cause/capability gap.
2. Prefer inheritance from the clean canonical owner.
3. Specify the smallest add/delete/replace delta and intended post-change action.
4. Preserve purpose, authority, evidence, safety and stop boundaries.
5. Define observable outcome, test, rollback/rejection condition and owner.
6. Apply existing authority accurately. the Library owner's 4 October 2026 standing instruction authorizes bounded evidence-backed Skill improvements and creation under AGENTS; execute that authorized capture rather than requesting the same approval again. Changes outside that boundary remain proposals until separately authorized. Preserve the source and evidence; staging is not acceptance, deployment or merge.

## Benchmark case

A missed stop rule yields one bounded wording change with a named regression test, not a broad rewrite.

## Anti-patterns

- Using confidence as fitness evidence
- Changing purpose inside an amendment
- Self-approving the proposal

## Stop

Stop after completing and verifying already-authorised bounded capture, with acceptance/validation status stated separately; otherwise stop with a testable proposal, documented no-change result or precise evidence/access/allocation/authority blocker.

## Matt Pocock method extension — 2026-10-10

After an observed work failure or correction, separate an environment/tool constraint from a repeatable judgement failure. Propose a mechanical check for reliably machine-detectable errors and a narrowly triggered instruction for judgement errors. Name the canonical owner, supporting observation, normal/negative case and the smallest useful delta; verify that the fix preserves authority and stop conditions. Learning capture stays within the current work and Library rules; it is not permission for unrelated audits, wholesale prompt rewrites or new recurring jobs.
