# SKILL-0118 — Reusable-Learning Classification

## Purpose

Classify a confirmed learning into the correct durable Library owner.

## Intent routing contract

Activate only for capture learning, skill or knowledge, reusable method or equivalent intent. This Skill owns one action-level job and does not replace adjacent associated Skills.

## Method

1. Ask whether the work changed a reusable expert method.
2. File a changed reusable technique in the existing Skill that owns that job.
3. When a technique is verified, distinct, repeatable and not already covered, automatically create its Skill on staging through SKILL-0197 and the serialized ID/folder workflow. the Library owner's 4 October 2026 standing instruction authorizes bounded reusable Skill capture; a suggestion alone does not satisfy it.
4. File stable domain facts as Knowledge; combine Skills for one defined outcome in a Playbook; orchestrate Playbooks or nested Workflows in governed Workflows/FLOW records. Preserve current owners; do not migrate existing records automatically.
5. Keep task-local detail in its governed work record.
6. Preserve source, date, context and acceptance evidence.

## Anti-patterns

- Creating a Skill for a one-off fact.
- Leaving a mature repeated method only in chat.
- Duplicating an existing capability under a new title.

## Benchmark case

A newly proven method for diagnosing Qlik composite keys updates the relevant Skill; the specific failing key population remains in the Ticket or Knowledge record.

## Output and evidence

Record inputs, direct evidence, result, residual uncertainty, owner and next action.

## Stop

Stop when the learning is unverified or its canonical owner cannot be determined.
