# Decisions — `DEC`

A standalone record of a choice that was made and why. Not the work itself — the decision behind it.

Filenames: `DEC-<NNNN>-<slug>.md`

Create from `_TEMPLATE.md` using `_HOW-TO-CREATE.md`.

## Before changing this folder

- File only a material choice and its reasoning; keep execution detail in the related Project or Ticket.
- For a new record, reserve the `DEC` ID, satisfy base frontmatter, use `decided` or `superseded` status, and add evidence-backed reciprocal links.
